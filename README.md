# ChatGPT Clone

A simple ChatGPT-like web app built with Next.js (frontend only).

## Features

- Chat interface similar to ChatGPT
- Mock responses (no backend required)
- Responsive design
- TypeScript support

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Note

This is a frontend-only implementation with mock responses. To connect to a real AI service, you would need to implement API routes or connect to external services.
